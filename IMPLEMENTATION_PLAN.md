# CertiProof implementation

1. Empty-workspace foundation: supported runtime, pinned dependencies, private database schema, keys, SSR authentication, production build.
2. Integrated issuance, immutable PDF storage, signed manifest/ledger, verification and revocation.
3. Local browser PDF/image parsing, guided fixtures, result states and cancellation.
4. Audit/checkpoints, isolated integrity lab, privacy and recoverable deletion.
5. Responsive accessible UI, policies, support, operator tools and recovery.
6. Automated checks, reviewed hosted migrations, public deployment, persistence rehearsal and owner second-device check.

Required external services: GitHub Free private repository, Vercel Hobby, Supabase Free. Never use a mock backend for release. No deployment or hosted test is complete until observed.
