## Internet failure fallback

An evidence pack is a **saved snapshot**, not a live verifier. Show downloaded fictional PDFs, exported signed ledger/checkpoints and saved screenshots/recording. Explain that current revocation cannot be checked while unavailable. Never display a cached active result as live. Use audit:checkpoint against saved exports with the retained public key; the local audit command does not require a database when both exports are supplied, but installed dependencies/key-ring configuration are needed. Do not label the normal hosted-Supabase local app fully offline.

The shareable judge pack must exclude private keys, credentials, backups, Auth sessions, recipient private data and request tokens. Public signed ledger copies/public keys and deliberately fictional example PDFs are appropriate. Until hosted fixture generation runs, the real evidence pack is pending rather than fabricated.
